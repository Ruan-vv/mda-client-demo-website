# NovaFix Demo Website

A simple responsive one-page demo website.

## Upload to GitHub
1. Create a new repository.
2. Upload `index.html`.
3. Commit the file.

## Deploy on Netlify
1. Choose **Add new project**.
2. Import from GitHub.
3. Select the repository.
4. Leave the build command blank.
5. Set the publish directory to `.` if requested.
6. Deploy.

The contact form is a front-end demonstration and displays a success message. It does not send email.
